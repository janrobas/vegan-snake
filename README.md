# Veganska Kača

Kača z gladkim premikanjem, ki je samo vegansko hrano.

## Kako igrati
Vsaka igra je omejena na 3 minute. Kača se ne sme ugrizniti ali zapustiti igralnega prostora. Veganska hrana prinese 1 točko, neveganska pa odnese 3.
